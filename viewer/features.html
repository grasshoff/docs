Viewer Features

Interactive navigation, rendering, and document exploration

Overview

AI-Viewer provides a rich set of features for exploring PDAI documents. This guide covers navigation, viewing modes, mathematical rendering, agent output layers, and customisation options.

Core Features

Universal PDAI Support

AI-Viewer displays any PDAI-compliant document using page-centric structure:

pdai/DocumentName/
└── pages/
    └── page_NNN/
        ├── page_NNN.png
        ├── page_NNN.xml
        ├── page_NNN.html
        └── page_NNN_translation_english.xml

  • Page-centric loading — All page files from one folder

  • Consistent naming — page_NNN[_agent].ext pattern

  • Underscore convention — No hyphens in filenames

High-Quality Display

  • High-resolution images — Supports 600+ DPI page images

  • Crisp text rendering — Proper font handling

  • Zoom capabilities — From 25% to 500%

  • Smooth scaling — Anti-aliased image display

Viewing Modes

Document Mode (Press D)

Dual-pane layout for reading:

Pane Content
Left Page image (pages/page_NNN/page_NNN.png)
Right OCR text or translation

Language Selection:

Language Source
Original pages/page_NNN/page_NNN.html
Deutsch pages/page_NNN/page_NNN_translation_german.xml
English pages/page_NNN/page_NNN_translation_english.xml

Agent Mode (Press A)

Three-pane layout for agent work:

Pane Content
Left Source input (image or XML)
Middle Agent output (rendered or raw XML)
Right Agent navigator and controls

Agent Navigator Features:

  • Browse available agents by category

  • View agent configuration (model, template)

  • Process new pages with “Brew Agent”

  • Check processing status

Segment Navigation

When a document has segment definitions in manifest.json:

How It Works

  1. Dropdown appears with segment types (letters, chapters, paragraphs)

  2. Select a segment to jump directly to its start page

  3. View metadata for the selected segment (dates, authors, titles)

Segment Types

Type Use Case Metadata Displayed
chapters Scholarly treatises Title, number, page range
paragraphs Numbered arguments Number, start text
letters Correspondence editions Sender, recipient, date, place
documents Diplomatic acts Parties, date, reference

Example: Letter Navigation

For the Euler-Goldbach correspondence:

Segment dropdown: "Letters"
├── Letter 1 (Euler → Goldbach, 1729-10-13)
├── Letter 2 (Goldbach → Euler, 1729-12-01)
├── Letter 3 (Euler → Goldbach, 1730-01-15)
└── ...

Agent Output Layers

Available Agents

The viewer displays agents from ai-orchestrator.yml or defaults:

Agent Output File Description
English Translation page_NNN_translation_english.xml Translated text
German Translation page_NNN_translation_german.xml Translated text
OCR Enhanced page_NNN_ocr_enhanced.xml Improved OCR

Viewing Agent Output

In Document Mode:

  • Use language dropdown to switch translations

In Agent Mode:

  • Select agent from navigator

  • View rendered output or raw XML

  • Click “Brew Agent” to generate new output

Output Display Options

View Description
Rendered Formatted HTML with styling
XML Raw XML source

<!-- Display mathematics -->

URL Navigation

URL Parameters

Parameter Description Example
doc Document path doc=pdai/E57
page Starting page (0-indexed) page=5
mode View mode mode=agent
lang Language lang=english

Example URLs

# Home catalog
http://localhost:4100/ai-viewer/viewer.html

# Specific document
http://localhost:4100/ai-viewer/viewer.html?doc=pdai/E57

# Specific page
http://localhost:4100/ai-viewer/viewer.html?doc=pdai/E57&page=25

# Agent mode
http://localhost:4100/ai-viewer/viewer.html?doc=pdai/E57&mode=agent

## Overview

AI-Viewer provides a rich set of features for exploring PDAI documents. This guide covers navigation, viewing modes, mathematical rendering, agent output layers, and customisation options.

## Core Features

### Universal PDAI Support

AI-Viewer displays any PDAI-compliant document using page-centric structure:

```
pdai/DocumentName/
└── pages/
    └── page_NNN/
        ├── page_NNN.png
        ├── page_NNN.xml
        ├── page_NNN.html
        └── page_NNN_translation_english.xml
```

- **Page-centric loading** — All page files from one folder

- **Consistent naming** — `page_NNN[_agent].ext` pattern

- **Underscore convention** — No hyphens in filenames

### High-Quality Display

- **High-resolution images** — Supports 600+ DPI page images

- **Crisp text rendering** — Proper font handling

- **Zoom capabilities** — From 25% to 500%

- **Smooth scaling** — Anti-aliased image display

## Viewing Modes

### Document Mode (Press D)

Dual-pane layout for reading:

| Pane | Content |
|------|---------|
| **Left** | Page image (`pages/page_NNN/page_NNN.png`) |
| **Right** | OCR text or translation |

**Language Selection:**

| Language | Source |
|----------|--------|
| Original | `pages/page_NNN/page_NNN.html` |
| Deutsch | `pages/page_NNN/page_NNN_translation_german.xml` |
| English | `pages/page_NNN/page_NNN_translation_english.xml` |

### Agent Mode (Press A)

Three-pane layout for agent work:

| Pane | Content |
|------|---------|
| **Left** | Source input (image or XML) |
| **Middle** | Agent output (rendered or raw XML) |
| **Right** | Agent navigator and controls |

**Agent Navigator Features:**

- Browse available agents by category

- View agent configuration (model, template)

- Process new pages with "Brew Agent"

- Check processing status

| `paragraphs` | Numbered arguments | Number, start text |
| `letters` | Correspondence editions | Sender, recipient, date, place |
| `documents` | Diplomatic acts | Parties, date, reference |

### Example: Letter Navigation
