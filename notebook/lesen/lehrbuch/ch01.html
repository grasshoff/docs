Chapter 1: A first notebook

1 How many people wrote to or from Pirckheimer?

The register letters_resolved of the Pirckheimer edition lists one letter per row, with the sender and the recipient as entity ids. Every letter has Pirckheimer on one side. The other side is his correspondent.

How many correspondents did Pirckheimer have between 1520 and 1530, and how many letters do they share?

Partitur
---
id: first-count
display: kennzahl
duckdb:
  - alias: main
    path: $PDAI_COLLECTIONS/pirckheimer/pirckheimer.duckdb
    read_only: true
partiturs:
  - id: duckdb-read
    input:
      sql: |
        WITH l AS (
          SELECT CASE WHEN sender_id = 'ent_pirckheimer'
                      THEN recipient_id ELSE sender_id END AS partner,
                 TRY_CAST(left(date_when, 4) AS INTEGER) AS year
          FROM letters_resolved
        )
        SELECT count(DISTINCT partner) AS n_correspondents,
               count(*) AS n_letters
        FROM l
        WHERE year BETWEEN 1520 AND 1530
artefacts:
  - name: count
    kind: table
    file: count.json
---

2 Who were they?

List Pirckheimer's correspondents between 1520 and 1530 with the number of letters each shares with him, the most frequent first.

Partitur
---
id: first-list
depends_on: [first-count]
display: tabelle
duckdb:
  - alias: main
    path: $PDAI_COLLECTIONS/pirckheimer/pirckheimer.duckdb
    read_only: true
partiturs:
  - id: duckdb-read
    input:
      sql: |
        WITH l AS (
          SELECT CASE WHEN sender_id = 'ent_pirckheimer'
                      THEN recipient_id ELSE sender_id END AS partner,
                 TRY_CAST(left(date_when, 4) AS INTEGER) AS year
          FROM letters_resolved
        )
        SELECT e.canonical AS name, count(*) AS count
        FROM l JOIN ent_canonical AS e ON e.ent_id = l.partner
        WHERE year BETWEEN 1520 AND 1530
        GROUP BY e.canonical
        ORDER BY count DESC, name
artefacts:
  - name: partners
    kind: table
    file: partners.json
---
List Pirckheimer's correspondents between 1520 and 1530 with the number of
letters each shares with him, the most frequent first.
